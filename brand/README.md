# AERA brand kit

The AERA logo is **Express**: a white A on a navy tile with a light-blue bullet train running
through it as the crossbar, trailed by two speed lines. It was chosen on 19 October 2026 from six
directions explored from the earlier Bullet A (record in `history/`). The rules and every version
are in the guideline.

| Folder | What is in it |
| --- | --- |
| `guideline/AERA_Brand_Guideline.pdf` | The brand guideline (14 A4 landscape pages): the name, the mark's meaning, construction, clear space, versions, lockups, colour, type, misuse, applications and the live app |
| `logo/svg/` | Every version and lockup as SVG (vector, text outlined) |
| `logo/png/` | The same as transparent PNG, plus app icon, social avatar and small sizes |
| `logo/pdf/` | Mark and main lockups as vector PDF for print |
| `logo/favicon.ico` | 16, 32 and 48 px |
| `mockups/` | The logo in use: home screen, splash and app bar, browser tab, business card, poster, title slide, staff badge, social profile, and screenshots of the live app |
| `history/` | Earlier marks (v0 ridership curve, v1 Bullet A) and the 17 Oct exploration board, kept as the record of how Express was chosen (not in the guideline) |
| `word/` | Word report template with the A1 frame border (`.dotx`), a blank and a sample `.docx`, the fonts, the frame artwork and the border proposals |
| `tools/` | `wordmark.py` turns the Plus Jakarta Sans wordmark into outlines (`wordmark.json`) |

## Which file to use

- App icon, avatar, slides: `aera-mark` (on its tile).
- Documents on white: `aera-lockup-horizontal`, or `aera-mark-on-light` when the name is already on the page.
- Navy or dark backgrounds: the `-reverse` lockups or `aera-mark-on-dark` (no tile; it would vanish).
- 24 px and below: `aera-mark-small` (no speed lines, no side window).
- One-colour print, stamps, engraving: `aera-mark-mono-black` / `aera-lockup-mono-black`.
- Android adaptive icon: `aera-mark-maskable`. iPhone home screen: `aera-app-icon-ios-1024.png`.

## Rebuilding

Everything is generated by `brand/build.mjs` from one drawing of the mark, so all versions stay
identical. It also writes the app's `frontend/public/icon.svg`, `frontend/public/icons/*.png` and
`frontend/app/favicon.ico`. The app's top-bar mark (`LogoMark` in
`frontend/components/TopBar.tsx`) uses the same geometry; change both together.

```bash
node brand/build.mjs           # needs Google Chrome and frontend/node_modules (sharp)
```

`mockups/app-*.png` are screenshots of the running app (`npm run dev`), taken by hand; the
guideline includes them when present. To change the wordmark, rerun `tools/wordmark.py` with the
Plus Jakarta Sans variable font (instructions in the script).

## Word report template

- **`word/AERA_Report_Template.dotx`**: double-click for a new report. A4 page with the navy
  frame, the mark in the top-left corner, a running head and the page number in a navy pill on
  the bottom edge, on every page. Styles: Kicker, Heading 1 to 3, Caption, Quote, List Bullet and
  the AERA Table table style.
- **`word/AERA_Report_Blank.docx`**: the same as a plain document. **`word/AERA_Report_Sample.docx`**
  shows every style on two pages.
- To add the frame to an existing report, open the blank file and paste your content in, or copy
  its header into your document (double-click the header, select all, copy).
- **Fonts:** Plus Jakarta Sans is embedded, but Word for Mac does not always load embedded fonts.
  Install the three files in `word/fonts/` (double-click, Install) on any Mac that edits the report.
  They are free under the SIL Open Font License (`word/fonts/OFL.txt`).
- `word/border/aera-frame-a4.svg|png` is the same frame as one full-page image, for Pages, Google
  Docs or Canva.
- Rebuild: `node brand/build.mjs`, then
  `uv run --no-project --with python-docx --with fonttools python brand/word/build_word.py <PlusJakartaSans[wght].ttf> <OFL.txt>`.
